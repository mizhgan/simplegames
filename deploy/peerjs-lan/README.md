# Игра по сети в локальной сети без интернета

Сайт — это обычные статические файлы, их может отдавать любой веб-сервер. Например, Apache из `/var/www/html/games/`. Без интернета работают одиночные игры, игры с компьютером и вдвоём на одном устройстве.

Для **игры по сети** на том же компьютере работают два сервера:

- **сервер знакомств PeerJS** (порт 9000/tcp) — через него браузеры находят друг друга;
- **STUN/TURN** (порт 3478/udp, пересылка 49160–49200/udp). Chrome и Firefox прячут адрес устройства за случайным именем `….local`, а найти его в сети получается не всегда. Через STUN браузер узнаёт свой настоящий адрес. Если напрямую не соединиться, например в гостевом Wi-Fi с изоляцией устройств, TURN пересылает ходы через этот компьютер.

Если сайт открыт по адресу из локальной сети, он сам ищет оба сервера на том же компьютере. Ничего настраивать на сайте не нужно. Локальным считается адрес вида `192.168.…`, `10.…`, `172.16–31.…`, `localhost`, имя компьютера без точки или `*.local` / `*.lan` / `*.home.arpa`.

## Установка

1. **На любом Linux-компьютере с интернетом** соберите комплект (root не нужен):

   ```sh
   bash deploy/peerjs-lan/prepare.sh        # обычный компьютер (x64)
   bash deploy/peerjs-lan/prepare.sh arm64  # Raspberry Pi 4/5 с 64-битной системой
   ```

   Получится `deploy/peerjs-lan/peerjs-lan-x64.tar.gz` (около 50 МБ): в нём Node.js, PeerJS и STUN/TURN (node-turn).

2. **Перенесите архив** на компьютер в локальной сети, где лежит сайт, и установите:

   ```sh
   tar -xzf peerjs-lan-x64.tar.gz
   cd peerjs-lan
   sudo bash install.sh
   ```

   Скрипт поставит службу `peerjs-lan` (systemd, автозапуск) и откроет порты 9000/tcp, 3478/udp и 49160–49200/udp в ufw или firewalld, если они включены. В конце он напечатает адреса, по которым открывать сайт.

   **Обновление:** соберите новый архив и снова запустите `install.sh`. Старая установка заменится.

   Если у этого компьютера временно есть интернет, шаг 1 можно пропустить. Достаточно скопировать папку `deploy/peerjs-lan` и запустить `sudo bash install.sh`: недостающее скрипт скачает сам.

3. **Проверка:** откройте `http://<адрес-компьютера>:9000/peerjs/id`. Должна вернуться случайная строка. Затем откройте игру с двух устройств по адресу `http://<адрес-компьютера>/games/` и нажмите «По сети».

## Что ещё стоит знать

- **Голосовой чат** в играх на компанию работает только по HTTPS. На `http://192.168.…` браузер не даст доступ к микрофону.
- **Офлайн-режим, уведомление о новой версии и установка как приложение** тоже требуют HTTPS. По обычному HTTP сайт просто каждый раз грузится с сервера.
- **Гостевой Wi-Fi** с изоляцией клиентов: устройства не видят друг друга напрямую, и ходы идут через TURN на компьютере с сайтом.
- **Сменился IP-адрес компьютера** (например, его выдаёт роутер по DHCP): перезапустите службу командой `sudo systemctl restart peerjs-lan`. Ещё лучше закрепить адрес за компьютером в роутере.
- **Без сервера знакомств** можно играть вдвоём через «Ручной режим» в окне приглашения: игроки обмениваются кодами вручную.
- **Другие порты:** поменяйте `PORT` / `TURN_PORT` в `install.sh` и `LAN_PORT` / `LAN_TURN_PORT` в `sg/js/src/net/10-config.js`, затем пересоберите сайт командой `python3 tools/build.py`.
- **Управление службой:**
  - `systemctl status peerjs-lan` — состояние;
  - `journalctl -u peerjs-lan -n 50` — журнал;
  - `sudo systemctl disable --now peerjs-lan` — выключить.
