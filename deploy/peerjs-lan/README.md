# Игра по сети в локальной сети без интернета

Сайт — это обычные статические файлы, их может отдавать любой веб-сервер. Например, Apache из `/var/www/html/games/`. Без интернета работают одиночные игры, игры с компьютером и вдвоём на одном устройстве.

Для **игры по сети** нужен сервер знакомств PeerJS. Через него браузеры находят друг друга, а дальше ходы идут напрямую. Если сайт открыт по адресу из локальной сети, он сам ищет сервер знакомств на том же компьютере, на порту **9000**. Ничего настраивать на сайте не нужно. Локальным считается адрес вида `192.168.…`, `10.…`, `172.16–31.…`, `localhost`, имя компьютера без точки или `*.local` / `*.lan` / `*.home.arpa`.

## Установка

1. **На любом Linux-компьютере с интернетом** соберите комплект (root не нужен):

   ```sh
   bash deploy/peerjs-lan/prepare.sh        # обычный компьютер (x64)
   bash deploy/peerjs-lan/prepare.sh arm64  # Raspberry Pi 4/5 с 64-битной системой
   ```

   Получится `deploy/peerjs-lan/peerjs-lan-x64.tar.gz` (около 50 МБ): в нём Node.js и peerjs-server.

2. **Перенесите архив** на компьютер в локальной сети, где лежит сайт, и установите:

   ```sh
   tar -xzf peerjs-lan-x64.tar.gz
   cd peerjs-lan
   sudo bash install.sh
   ```

   Скрипт поставит службу `peerjs-lan` (systemd, автозапуск) и откроет порт 9000 в ufw или firewalld, если они включены. В конце он напечатает адреса, по которым открывать сайт.

   Если у этого компьютера временно есть интернет, шаг 1 можно пропустить. Достаточно скопировать папку `deploy/peerjs-lan` и запустить `sudo bash install.sh`: недостающее скрипт скачает сам.

3. **Проверка:** откройте `http://<адрес-компьютера>:9000/peerjs/id`. Должна вернуться случайная строка. Затем откройте игру с двух устройств по адресу `http://<адрес-компьютера>/games/` и нажмите «По сети».

## Что ещё стоит знать

- **Голосовой чат** в играх на компанию работает только по HTTPS. На `http://192.168.…` браузер не даст доступ к микрофону.
- **Офлайн-режим, уведомление о новой версии и установка как приложение** тоже требуют HTTPS. По обычному HTTP сайт просто каждый раз грузится с сервера.
- **Гостевой Wi-Fi.** Если в сети включена изоляция клиентов, устройства не видят друг друга, и игра по сети не соединится. Выход — обычная домашняя или рабочая сеть.
- **Без сервера знакомств** можно играть вдвоём через «Ручной режим» в окне приглашения: игроки обмениваются кодами вручную.
- **Другой порт:** `sudo bash install.sh 9100` и поменять `LAN_PORT` в `sg/js/src/net/10-config.js`, затем пересобрать сайт командой `python3 tools/build.py`.
- **Управление службой:**
  - `systemctl status peerjs-lan` — состояние;
  - `journalctl -u peerjs-lan -n 50` — журнал;
  - `sudo systemctl disable --now peerjs-lan` — выключить.
