Сайт с простыми браузерными играми. Чистый HTML, CSS и JavaScript: без сборки, бэкенда и базы данных.

Кроме игр на сайте есть:

- светлая и тёмная тема (по умолчанию берётся тема системы, выбор запоминается);
- главная с полками по разделам («Вдвоём по сети», «Компанией», «Головоломки»…), поиском (клавиша «/»), фильтрами по категории и числу игроков и компактным видом сетки; картинки карточек грузятся лениво из `games/<игра>/thumb.svg`;
- избранные игры (звёздочка на карточке) и блок «Вы недавно играли»;
- «Игра дня»: каждый день новое задание в одной из игр и серия дней подряд;
- достижения (`achievements.html`) с уведомлениями при получении;
- игра по сети с другом (WebRTC) в 62 играх на двоих, включая карточные и игры в реальном времени; счёт серии, реванш, реакции, список открытых комнат «Ищу соперника» и зрители (до 10 на партию) по ссылке «👁 Зрителям»;
- рейтинг Эло по каждой игре, недавние соперники со счётом личных встреч и приглашение «в один клик»: приглашение всплывает у друга, если у него открыта любая игра сайта (страница «Достижения» показывает рейтинг и соперников);
- 21 игра на компанию (от 2–4 до 12 человек): у каждого своё устройство, свои карты и роли, общий чат и голосовой чат, боты вместо недостающих игроков, зрители и возвращение в игру после перезагрузки страницы;
- турнир в комнате: олимпийская сетка или круговой по любой игре на двоих, матчи открываются в новой вкладке, итоги попадают в таблицу сами;
- офлайн-режим: сайт устанавливается как приложение (PWA) и работает без интернета;
- звуковые эффекты с кнопкой вкл/выкл в шапке (по умолчанию выключены): звуки синтезируются через Web Audio API, аудиофайлов нет;
- адаптивная вёрстка под телефоны, планшеты и десктоп;
- рекорды в `localStorage` браузера, они же показываются на карточках главной страницы.

Словари «Вордли» (`games/wordle/words.js`), «Филворда» и «Виселицы» (`sg/data/nouns.js`), «Балды» и «Слов из слова» (`sg/data/balda-dict.js`) собраны из морфологического словаря OpenCorpora (pymorphy3): существительные в начальной форме. Используются частотные слова (по данным wordfreq), из них вручную убраны имена собственные и неуместные слова. Компьютер в «Балде», «Эрудите» и «Словах из слова» ходит только словами из списка `BALDA_AI`; из него дополнительно убраны слова, которые частые лишь по написанию («став» — деепричастие, «стер» — глагол), падежные формы других слов, имена собственные и жаргон. Стоп-лист — `tools/words/ai-stoplist.txt`, применяет его `python3 tools/words/clean_ai.py`, новых кандидатов подсказывает `--suggest` (нужен `pymorphy3`), проверенные хорошие слова — в `tools/words/ai-keep.txt`. Игроку все слова общего словаря по-прежнему засчитываются.

## Развёртывание

Скопируйте содержимое репозитория в корень сайта на хостинге (обычно `public_html`, `www` или `/var/www/<домен>`), например:

```bash
rsync -av --delete --exclude '.git' ./ user@host:/var/www/example.com/
```

Больше ничего не нужно: сервер просто отдаёт статические файлы.

- **Apache**: `.htaccess` уже включает `index.html`, страницу 404, сжатие и кэширование.
- **nginx**: минимальный конфиг:

  ```nginx
  server {
      server_name example.com;
      root /var/www/example.com;
      index index.html;
      error_page 404 /404.html;
      location / { try_files $uri $uri/ =404; }
  }
  ```

- Подойдёт и любой статический хостинг: GitHub Pages, Netlify, Cloudflare Pages и т. п.

Все ссылки между страницами относительные, поэтому сайт работает и из подпапки, и при открытии `index.html` прямо с диска. Исключение — `404.html`: в ней абсолютные пути от корня домена, потому что сервер может отдать её по любому адресу.

## Офлайн-режим

`sw.js` кеширует все файлы сайта при первом визите, поэтому игры открываются и без интернета, а сайт можно установить на телефон или компьютер как приложение. Страницы загружаются «сначала из сети», поэтому обновления видны сразу.

После добавления или изменения файлов пересоберите список кешируемых файлов:

```bash
python3 tools/build.py
```

Офлайн-режим работает только по HTTPS (или на `localhost`).

## Игра по сети

В пошаговых играх на двоих есть режим «🌐 По сети». Один игрок нажимает его и отправляет другу ссылку (или код комнаты), друг открывает её — и игра начинается. Ходы передаются напрямую между браузерами по WebRTC, сервер сайта для этого не нужен.

- Чтобы браузеры нашли друг друга, используется бесплатный публичный сервер знакомств PeerJS (`0.peerjs.com`) и его TURN-серверы — через них идёт только обмен приглашениями, а если прямое соединение невозможно, TURN пересылает трафик.
- Если сервер знакомств недоступен, включается ручной режим: хозяин отправляет ссылку-приглашение, гость присылает в ответ код, хозяин вставляет его — без каких-либо серверов, кроме STUN.
- Бесплатные публичные серверы PeerJS работают без гарантий. Если игрокам не удаётся соединиться (чаще всего в мобильном интернете, где прямое соединение невозможно), в окне ошибки видна диагностика: дошли ли до сервера, ответил ли друг, удалось ли прямое соединение и есть ли ретранслятор (TURN).
- Для надёжной игры поднимите на своём сервере TURN ([coturn](https://github.com/coturn/coturn)) и, при желании, свой сервер знакомств ([peerjs-server](https://github.com/peers/peerjs-server)) и пропишите их в блоке `CONFIG` в начале `sg/js/net.js` (`iceServers` и `peerServer`). Для проверки без правки файлов сервер знакомств можно задать в браузере: `localStorage['sg:peer-server'] = '{"host":"peer.example.com","port":443,"path":"/","secure":true}'`.
- Чтобы добавить сеть в игру: `SG.net.setup({ game, modeEl, onConnect(role), onMessage(msg), onDisconnect(voluntary), onRematch() })`, затем `net.send({...})` на каждый ход и `net.result('win' | 'lose' | 'draw')` в конце партии (счёт серии и кнопка «Реванш»). Хозяин (`host`) задаёт параметры партии, гость (`guest`) их принимает.
- Новые пошаговые игры проще делать на каркасе `SG.duel` (`sg/js/duel.js`): игра описывает правила (`create`, `legal`, `apply`, `over`) и отрисовку, а режимы, очередь ходов, счёт, отмена хода и сеть — общие. Раздача карт и фишек идёт от общего «зерна», поэтому у обоих игроков по сети всё совпадает. Игры в реальном времени — на `SG.rt` (`sg/js/rt.js`).
- **Зрители.** По ссылке `#watch=код` (кнопка «👁 Зрителям» в полоске игры и в окне приглашения, есть и у хозяина, и у гостя) до 10 человек смотрят партию, не играя. Зрители подключаются к хозяину, он пересылает им ходы. В играх на `SG.duel` и `SG.rt` зритель видит нейтральную картину (карты и фишки в руках закрыты), в остальных — «зеркало» экрана хозяина, где его секреты (рука, расстановка флота, буквы, загаданное слово) спрятаны через `opts.mirrorMask`.
- **Игры на компанию** (`sg/js/party.js`) работают звездой: хозяин комнаты хранит всё состояние партии, гости присылают действия и получают свой «вид» — только то, что им положено видеть (свои карты, свою роль). Ссылка `#party=код` приглашает игрока, `#pwatch=код` — зрителя. Опоздавшие после начала партии смотрят как зрители, а игрок, перезагрузивший страницу, возвращается на своё место. Игра описывает `create`, `view(state, id)`, `act(state, id, action)`, `tick` для таймеров и `ai` для ботов; для потоковых данных (рисунок в «Крокодиле») есть `relay`.
- **Рейтинг и соперники.** При знакомстве игроки обмениваются карточкой `{ id, name, elo }`: случайный постоянный номер браузера, имя и рейтинг в этой игре. После партии каждый пересчитывает свой рейтинг Эло (K = 40 первые 10 партий, потом 24) и счёт личных встреч; всё хранится только в `localStorage` (`sg:elo`, `sg:rivals`). Рейтинг — доверительный, как и сама игра по сети.
- **Приглашения.** Пока открыта любая игра сайта и есть недавние соперники, браузер слушает свой «почтовый ящик» на сервере знакомств (адрес — хэш номера игрока). В окне приглашения есть список «Позвать недавнего соперника»: приглашение со ссылкой на комнату всплывает у друга, он жмёт «Играть». Принимаются только ссылки на этот же сайт; отключить можно на странице «Достижения».
- **Голосовой чат** в играх на компанию: кнопка «🎤 Голос» в лобби и за столом. Звук идёт напрямую между участниками (каждый с каждым через PeerJS), хозяин лишь рассылает список, кто в голосе. Микрофон включается только по кнопке, есть кнопка выключения микрофона.
- **Турнир** (`games/tournament/`): комната на `SG.party` строит сетку, у каждого матча свой код комнаты. Кнопка «Играть» открывает игру по ссылке `#thost=код` (хозяин матча) или `#tjoin=код` (гость); по окончании партии `net.result` сообщает итог во вкладку турнира через `BroadcastChannel`.
- Комнаты на сервере знакомств записаны под хэшем кода, а гость называет сам код при подключении — так список комнат на сервере не раскрывает приглашения. Комнату можно показать всем («Ищу соперника»): она появится в окне приглашения у других игроков той же игры. Для этого свой сервер знакомств должен отдавать список (`--allow_discovery`, уже включено в `deploy/peerjs/install.sh` — перезапустите скрипт, если ставили раньше).

### Свой TURN-сервер (coturn)

Без ретранслятора браузеры часто не могут соединиться, если кто-то из игроков в мобильном интернете: в окне ошибки это видно по строке «ретранслятор TURN: недоступен». Бесплатный TURN от PeerJS работает с перебоями, поэтому лучше поставить свой — нагрузка от пошаговых игр мизерная, хватит самой маленькой VPS.

**Установка одной командой** (чистая VPS с Ubuntu 22.04+/Debian 12+, от root). Заранее создайте DNS-запись A для поддомена (например, `turn.example.com`) на IP этой VPS:

```bash
curl -fsSLO https://raw.githubusercontent.com/mizhgan/simplegames/main/deploy/coturn/install.sh
bash install.sh turn.example.com you@example.com
```

Скрипт поставит coturn, получит сертификат Let's Encrypt (TURN по TLS на порту 443 проходит даже через строгие файрволы), настроит ограничения и запрет пересылки во внутренние сети, откроет порты в ufw и напечатает строку для `CONFIG.iceServers` в `sg/js/net.js`. Если у провайдера VPS есть свой файрвол, откройте в нём `80/tcp`, `443/tcp`, `3478/tcp+udp` и `49160–49250/udp`.

Вручную: `apt install coturn`, конфиг-образец — `deploy/coturn/turnserver.conf`.

**Проверка ретранслятора.** Откройте на сайте страницу `turn-test.html`: она соединит два канала в одном браузере только через ваш TURN (как у игроков, которым не удалось связаться напрямую) и покажет, на каком шаге сбой. Если адреса выдаются, а соединение не устанавливается — не открыт диапазон `49160–49250/udp` в файрволе хостера или VPS стоит за NAT (свежий `install.sh` это определяет и прописывает `external-ip=ВНЕШНИЙ/ВНУТРЕННИЙ`).

**Проверка до публикации.** Откройте игру, в консоли браузера выполните
`localStorage['sg:ice-servers'] = JSON.stringify([{urls: 'turn:turn.example.com:3478', username: 'simplegames', credential: 'пароль'}]); localStorage['sg:ice-policy'] = '"relay"'`
и обновите страницу (у друга — то же самое): соединение пойдёт только через ваш TURN. Отменить: `localStorage.removeItem('sg:ice-servers'); localStorage.removeItem('sg:ice-policy')`. Ещё один способ — страница [Trickle ICE](https://webrtc.github.io/samples/src/content/peerconnection/trickle-ice/): должен появиться кандидат типа `relay`.

### Свой сервер знакомств (peerjs-server)

По умолчанию игроки находят друг друга через бесплатный публичный `0.peerjs.com`. Чтобы не зависеть от него, поставьте свой сервер — можно на ту же VPS, что и coturn:

```bash
curl -fsSLO https://raw.githubusercontent.com/mizhgan/simplegames/main/deploy/peerjs/install.sh
bash install.sh            # домен возьмётся из сертификата coturn, порт 8443
```

Скрипт поставит Node.js (если нужно) и `peer`, запустит службу `peerjs` (со списком открытых комнат `--allow_discovery` для лобби «Ищу соперника») с TLS-сертификатом Let's Encrypt (продлевается автоматически) и напечатает строку для `CONFIG.peerServer` в `sg/js/net.js`. Порт 443 на этой VPS занят TURN, поэтому сервер слушает 8443 — откройте его и в файрволе хостера. Проверка: `https://домен:8443/peerjs/id` возвращает случайную строку.

Если свой сервер недоступен, сайт сам создаст комнату на публичном — к коду в ссылке добавится `-p`, чтобы гость пришёл туда же.

## Дизайн-система

- **Токены** — в `sg/css/src/tokens.css`: цвета поверхностей и текста, акценты, цвета игроков `--p1`…`--p8` (синий и красный — стороны в играх на двоих), игровые поля, тени, скругления, отступы, размеры текста, длительности анимаций и слои. - **Компоненты**: кнопки `.btn` / `.btn-primary` / `.btn-ghost`, переключатель `.seg` (`SG.segmented`), табло `.stats` / `.stat`, оверлей `.overlay`, карточка правил `.info-card`, уведомления `SG.toast({ icon, title, text, tone, actions })` и окно `SG.modal(html)` / `SG.modal.close()` (Esc закрывает).
- **Помощники для игр**: `SG.overlay()` — оверлей поверх поля (`show(заголовок, текст, кнопка)`, `hide()`, свойства `title`, `text`, `hidden`); `SG.record(ключ, { el, lower })` — рекорд в хранилище и на табло (`submit(значение)` возвращает `true`, если это новый рекорд). Заготовка `tools/build.py --new` уже использует оба.
- Посмотреть всё вместе в обеих темах — `styleguide.html`.

## Как добавить новую игру

Всё, что сайт знает об игре, лежит в её папке, а страницы и списки собирает `tools/build.py`:

1. `python3 tools/build.py --new <id> "Название"` — создаст `games/<id>/` с заготовками и добавит игру в конец `games/catalog.json` (порядок карточек на главной).
2. Заполните `meta.json`:
   - `title`, `description` (для поисковиков), `category` (`arcade`, `puzzle` или `board` — фильтр на главной), `tag` (подпись на карточке);
   - `card.text` и `card.colors` (градиент карточки), `best` (ключ рекорда в `SG.store` и подпись: `label`, `suffix`, `format: "time"`);
   - `online` / `party` — есть ли игра по сети и на компанию; `players` — `[мин, макс]` игроков (для фильтра на главной; игры с ботами начинаются с 1); `daily` — задания «Игры дня» (`[ключ, "win" | "max" | "min", сколько, текст]`);
   - `rules` — пункты «Как играть», `stats` — плашки над полем, `styles` и `scripts` — подключаемые файлы (помимо `common.js` и `game.js`), `readme` — строка для таблицы выше.
3. Разметку поля положите в `stage.html`, картинку карточки (SVG 160×100) — в `thumb.svg`, логику — в `game.js`. Общие функции доступны через `window.SG`: `SG.store`, `SG.sound.play('win')` (список звуков — в `PRESETS` в `common.js`), `SG.onSwipe`, `SG.touchKeys` (экранные кнопки аркад), `SG.segmented`, `SG.formatTime`, `SG.shuffle`, `SG.cssVar`. Для игр на двоих есть каркасы `SG.duel` и `SG.rt`, для игр на компанию — `SG.party`.
4. Запустите `python3 tools/build.py`: он соберёт `index.html` игры, карточку на главной, список игр и «Игру дня» в `site.js`, строку в README, список турнира и `sw.js`. Сгенерированные файлы руками не правьте — изменения пропадут при следующей сборке. `python3 tools/build.py --check` проверяет, что всё собрано (удобно перед коммитом).
