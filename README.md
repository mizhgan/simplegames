# SimpleGames

Сайт с простыми браузерными играми. Чистый HTML, CSS и JavaScript: без сборки, бэкенда и базы данных.

## Игры

| Игра | Папка | Управление |
| --- | --- | --- |
| Змейка | `games/snake/` | стрелки / WASD, свайпы, экранные кнопки |
| 2048 | `games/2048/` | стрелки / WASD, свайпы, отмена хода |
| Крестики-нолики | `games/tictactoe/` | мышь / касание, против компьютера (3 уровня) или вдвоём |
| Мемори | `games/memory/` | мышь / касание, поля 4×4, 5×4, 6×6 |
| Сапёр | `games/minesweeper/` | ЛКМ — открыть, ПКМ / долгое нажатие — флажок |
| Арканоид | `games/breakout/` | мышь, палец, стрелки / AD |
| Тетрис | `games/tetris/` | стрелки, пробел, Z / X / C, жесты и кнопки на телефоне |
| Птичка | `games/flappy/` | пробел / клик / касание |
| Судоку | `games/sudoku/` | мышь / касание, цифры с клавиатуры, заметки, подсказки |
| Пятнашки | `games/fifteen/` | клик по плитке, стрелки, свайпы; поля 3×3, 4×4, 5×5 |
| Четыре в ряд | `games/connect4/` | клик по столбцу / клавиши 1–7, против компьютера или вдвоём |
| Вордли | `games/wordle/` | экранная или обычная клавиатура (в т. ч. английская раскладка); слово дня и свободная игра |
| Косынка | `games/solitaire/` | перетаскивание или клик по карте, отмена, по 1 или 3 карты |
| Шашки | `games/checkers/` | русские правила, против компьютера (3 уровня) или вдвоём |
| Динозаврик | `games/dino/` | пробел / ↑ — прыжок, ↓ — пригнуться, касание и экранные кнопки |
| Линии | `games/lines/` | клик по шару и клетке, отмена хода, автосохранение |

Кроме игр на сайте есть:

- светлая и тёмная тема (по умолчанию берётся тема системы, выбор запоминается);
- фильтр игр по категориям на главной;
- адаптивная вёрстка под телефоны, планшеты и десктоп;
- рекорды в `localStorage` браузера, они же показываются на карточках главной страницы.

Словарь «Вордли» (`games/wordle/words.js`) собран из морфологического словаря OpenCorpora (pymorphy3): пятибуквенные существительные в начальной форме. Загадываются только частотные слова (по данным wordfreq), из них вручную убраны имена собственные и неуместные слова.

## Структура

```
index.html          главная страница
404.html            страница «не найдено»
sg/css/style.css    общие стили и темы
sg/js/common.js     общие утилиты (тема, рекорды, свайпы)
sg/img/             иконки
games/<игра>/       index.html + game.js (+ style.css) каждой игры
```

## Развёртывание

Скопируйте содержимое репозитория в корень сайта на хостинге (обычно `public_html`, `www` или `/var/www/<домен>`), например:

```bash
rsync -av --delete --exclude '.git' ./ user@host:/var/www/example.com/
```

Больше ничего не нужно: сервер просто отдаёт статические файлы.

- **Apache**: `.htaccess` уже включает `index.html`, страницу 404, сжатие и кэширование.
- **nginx**: минимальный конфиг:

  ```nginx
  server {
      server_name example.com;
      root /var/www/example.com;
      index index.html;
      error_page 404 /404.html;
      location / { try_files $uri $uri/ =404; }
  }
  ```

- Подойдёт и любой статический хостинг: GitHub Pages, Netlify, Cloudflare Pages и т. п.

Все ссылки между страницами относительные, поэтому сайт работает и из подпапки, и при открытии `index.html` прямо с диска. Исключение — `404.html`: в ней абсолютные пути от корня домена, потому что сервер может отдать её по любому адресу.

## Локальный запуск

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Как добавить новую игру

1. Скопируйте папку любой игры, например `games/snake/`, в `games/<новая>/`.
2. Поменяйте заголовок, описание и `game.js`. Общие функции доступны через `window.SG`: `SG.store`, `SG.onSwipe`, `SG.segmented`, `SG.formatTime`, `SG.shuffle`, `SG.cssVar`.
3. Добавьте карточку игры в `index.html`.
