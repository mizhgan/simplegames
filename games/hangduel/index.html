Как играть
  • Каждый загадывает существительное (4–12 букв) для соперника, а потом оба одновременно отгадывают слова друг друга по буквам.
  • Каждая неверная буква дорисовывает виселицу; на седьмой ошибке вы повешены.
  • Побеждает тот, кто отгадал слово с меньшим числом ошибок; если ошибок поровну — кто быстрее.
  • Справа видно, какие буквы вашего слова уже открыл соперник.
  • 🌐 По сети — играйте с другом на другом устройстве: нажмите «По сети» и отправьте ему ссылку (или отметьте «Ищу соперника»). После партии можно предложить реванш и отправить реакцию. Ваше слово остаётся только у вас: соперник узнаёт лишь, есть ли в нём названная буква. Друзья могут смотреть партию: кнопка «👁 Зрителям» даёт ссылку для просмотра.
