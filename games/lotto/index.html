Как играть

  • У каждого по две карточки: в трёх рядах по пять чисел от 1 до 90.
  • Игроки по очереди достают из мешка бочонки. Выпавшее число само закрывается на всех карточках, где оно есть.
  • Побеждает тот, кто первым закроет целый ряд (все пять чисел) на любой своей карточке. «Авто» достаёт бочонки само, Пробел — достать вручную.
  • У многих бочонков есть народные прозвища: 11 — «барабанные палочки», 77 — «топорики», 90 — «дедушка».
  • 🌐 По сети — играйте с другом на другом устройстве: нажмите «По сети» и отправьте ему ссылку (или отметьте «Ищу соперника»). После партии можно предложить реванш и отправить реакцию.
